# マインデュエル (Mine Duel)

1つの盤面を2人で交互に開き合う、対戦型マインスイーパー。

昔のWindows Minesweeperを思わせる配色で、地雷モード(即敗北 / 0点リセット / -5点)、
初手の安全設定、開始時1マス開放、制限時間、地雷だらけモードなど、対戦を盛り上げる
設定を選べます。

## 遊び方

1台のPC・スマホを2人で回して交互にプレイします。友達と同じ画面を見ながら遊んでください。
COM対戦(強さLv1〜4・Max)や、1人でタイムを計測する練習モードもあります。

PWA対応済みなので、スマホのブラウザで開いて「ホーム画面に追加」するとアプリのように使えます。
